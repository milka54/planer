# Планер — заметки и напоминания

Мобильное приложение для заметок с напоминаниями, разделами, голосовым вводом
и совместными «семейными» пространствами. Версия для Android (Flutter) и Windows.

## Возможности

- Заметки с заголовком, текстом, цветом и закреплением
- Разделы (папки) для группировки заметок
- Напоминания с календарём, разделами и **ежегодным повтором**
- Голосовые вложения к заметкам
- Кликабельные ссылки в тексте заметок
- Архив заметок и множественный выбор (перенос / удаление)
- Темы и фоны оформления, в том числе свои изображения
- Работа офлайн + облачная синхронизация (Firebase)
- **Семейные заметки:** общие пространства, задачи-чеклист, чат, приглашение по ссылке
- Версия для ПК (Windows) с синхронизацией с телефоном

## Установка на ПК

1. Скачайте `planer-setup.exe` из раздела [Releases](../../releases)
2. Запустите установку
3. Войдите тем же аккаунтом, что на телефоне — данные синхронизируются

## Разработка

Проект на Flutter. Основные команды:

```bash
flutter pub get
flutter build apk --release      # Android
flutter build windows --release  # Windows
```

Для сборки Windows-установщика нужен [Inno Setup](https://jrsoftware.org/):
```bash
"C:\Program Files\Inno Setup 7\ISCC.exe" installer\planer-setup.iss
```

## Структура проекта

- `lib/` — код приложения (Dart)
- `android/` — Android-обвязка
- `windows/` — Windows-обвязка
- `installer/` — скрипт установщика (Inno Setup)
- `firestore.rules` — правила безопасности Firestore
- `test/` — автотесты (синхронизация, безопасность, REST)

## Подпись Android

Файл подписи и пароль находятся в `android/key.properties`
и **не публикуются** (см. `.gitignore`).
